# Gandalf action

Private GitHub Action for running the Gandalf CLI against a checked-out WordPress
plugin or theme. Home: `github.a8c.com/Automattic/action-gandalf`.

Implementation is starting with the disposable `SecEx boundary proof` manual
workflow. The reusable action will be promoted only after the checkout, build,
authenticated scan, and artifact boundaries have been exercised on SecEx.

See [the boundary note](docs/boundary.md) for the experiment and acceptance criteria.
